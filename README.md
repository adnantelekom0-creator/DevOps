# DevOps Practitioner Labs

[devops-practitioner-labs](https://gitlab.com/devops-practitioner-labs) GitLab grubunda bulunan tüm eğitim laboratuvarlarının GitHub kopyası.

Her proje kök dizinde kendi klasöründe yer alır. İçerikler, ilgili projelerin **güncel hâlidir**; Git commit geçmişi aktarılmamıştır.
